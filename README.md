# AI業務時短診断アプリ

Difyを活用して構築した、事務作業の効率化を支援する診断アプリです。

作業回数や作業時間、現在の業務の進め方、困っていることなどを入力すると、月間・年間の作業時間を計算し、業務改善の方向性を提案します。

## 1. 開発の目的

日々の事務作業には、メール対応、書類作成、データ入力など、繰り返し発生する業務が数多くあります。

本アプリは、こうした業務を整理し、どこから改善に取り組めばよいかを考えるための診断ツールです。

## 2. 主な機能

* 入力された作業回数と作業時間から、月間・年間の作業時間を計算
* 業務内容や困りごとに応じた改善案の提示
* 削減時間を推定するために必要な情報の整理
* Googleフォームを利用した無料相談への案内

## 3. 使用技術

* Dify
* LLM
* Pythonによる計算処理
* Googleフォーム

## 4. 工夫した点

### 作業時間を計算する仕組み

LLMの回答だけに計算を任せず、Pythonによる計算処理を組み合わせました。

### 根拠のない削減効果を提示しない設計

入力情報が不足している場合、削減時間を無理に数値化せず、追加で必要な情報を示すようにしています。

### 実行しやすい改善案

利用者が最初に取り組める行動を提示し、業務改善の第一歩につなげることを目指しています。

## 6. 今後の改善

* 利用者の意見をもとに診断結果を改善
* 入力項目や案内文の分かりやすさを向上
* 実際の業務に合わせた改善案の精度を検証

## 7. 注意事項

本アプリは業務改善の方向性を整理するための診断ツールです。

実際の削減効果は、業務内容や運用方法によって異なります。表示された改善案や削減時間の目安は、実際の効果を保証するものではありません。
